# 2026-10-07 WebUSB(PTP)動作確認 — 手順と記録

仕様書 §4.2 / §5 M7 / U23。コードは書かずに、Google の web-gphoto2 デモで次の 2 点を確かめる。

1. Android の Chrome から WebUSB でカメラにつながり、撮影画像(またはライブビュー)を表示できるか
2. USB でつないだままでも、本体のシャッターボタン・有線リモートでレリーズできるか(本番のレリーズ経路を試しながら画像を取れるか)

必須機種の D7200・D7500 を優先する。任意機種(D7000 / D7100 / D800 / D810)は手元にあれば A だけでも見る。

## 持ち物

- Android スマホ(Chrome を最新に更新しておく)
- OTG アダプタ: USB-C オス → USB-A メス(スマホ側が micro-B なら micro-B → USB-A メス)
- 各カメラの純正 USB ケーブル(USB-A → カメラ側)
  - D7200 / D7100: 8 ピン独自形状(UC-E6 / UC-E17)
  - D7500: micro-B(UC-E20)
  - D7000: mini-B(UC-E4)
  - D800 / D810: USB 3.0 micro-B(USB 2.0 の micro-B ケーブルでも挿さる)
- 充電済みの電池、空きのある SD カード
- あれば有線リモート(MC-DC2、D800/D810 は 10 ピン用)

## A. web-gphoto2 デモでの接続・撮影

1. カメラの電源を入れる(レンズは MF、撮影モードは何でもよい)。
2. スマホとカメラを OTG アダプタ + USB ケーブルでつなぐ。
   - Android が「USB の用途」「このデバイスを開くアプリ」を聞いてきたら、**フォトやファイルなど他のアプリは選ばずに閉じる**(他のアプリがカメラを掴むと Chrome から使えない)。
3. Chrome で https://web-gphoto2.rreverser.com/ を開き、接続ボタンを押して、出てきた機器一覧からカメラを選ぶ。
4. 確認すること(ボタン名はデモの表示に従う):
   - 接続できるか。カメラの設定一覧が出るか
   - ライブビュー(プレビュー)が出るか
   - デモの撮影ボタンで撮影でき、撮った画像が表示されるか
5. つながらないときは、ケーブルを挿し直してから 3 をやり直す。エラー表示はそのまま書き留めるかスクリーンショットを撮る。

## B. USB 接続中のレリーズ(M7 の本題)

A でつながった状態のまま:

1. カメラ本体のシャッターボタンで撮れるか
2. 有線リモート(あれば)の半押し・全押しで撮れるか
3. B1・B2 で撮った画像に、デモの画面が反応するか(表示されなくても可。画像一覧から見られるかだけでも)
4. 何も操作せずに置いておくと、半押しタイマーオフ(表示消灯)になるか(接続中の消費電力に関係)
5. ケーブルを抜いたあと、カメラが普段どおり動くか

## C. 時間があれば(EP-5B と安定化電源があるとき)

安定化電源 9V → picowatt → EP-5B → カメラ で、仕様書 §5 の M1(待機電流)・M2(1 ショットの電流波形)・M4(給電し直したときに自動起動するか、撮影できるまでの時間)を見る。picowatt は既定設定でフルスケール約 4A。
